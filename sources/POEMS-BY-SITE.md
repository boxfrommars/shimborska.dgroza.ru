# Источники произведений по каталогу сайта

Индекс повторяет состав и порядок всех 93 записей из
[`resources/data/poems.php`](../resources/data/poems.php) и показывает, где
искать каждую опубликованную страницу. Полный состав локальных источников,
включая произведения вне каталога сайта, приведён в
[карте источников](POEMS.md).

Одна строка объединяет источники и языковые или переводные версии одной
страницы сайта. Отсутствие конкретной версии отмечается словами «на сайте нет
этой версии». Наличие версии определяется по основному тексту; отличие только
заголовка отмечается отдельно и не меняет положительного статуса. Отсутствие
локального файла не означает, что у текста нет внешнего источника.

Обозначения языковых версий: `PL` — польский оригинал, `RU` — русский перевод,
`EN` — английский перевод. «Страницы PDF» — порядковые страницы локального
файла, «печатные страницы» — пагинация самого издания.

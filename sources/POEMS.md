# Карта локальных источников произведений

Карта описывает локальный архив в двух направлениях. Раздел «По источникам»
показывает полный учтённый состав каждого логического источника, включая
материалы вне каталога сайта. Раздел «По каталогу сайта» повторяет порядок всех
93 записей из [`resources/data/poems.php`](../resources/data/poems.php) и
показывает, где искать каждую опубликованную страницу. Отсутствие локального
файла не означает, что у текста нет внешнего источника.

Обозначения языковых версий: `PL` — польский оригинал, `RU` — русский перевод,
`EN` — английский перевод. «Страницы PDF» — порядковые страницы локального
файла, «печатные страницы» — пагинация самого издания.

Если страница произведения существует, но конкретная версия из источника на
ней не опубликована, рядом с этой версией указано «на сайте нет этой версии».
Совпадение основного текста и отличие только заголовка отмечаются отдельно:
такой перевод считается опубликованным.

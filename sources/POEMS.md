# Карта локальных источников произведений

Карта повторяет порядок всех 93 записей из
[`resources/data/poems.php`](../resources/data/poems.php). Она описывает только
файлы, находящиеся в локальном каталоге `sources/`; отсутствие файла не
означает, что у опубликованного текста нет внешнего источника.
Если локальный файл содержит только не вошедшие в каталог произведения, его полный
состав фиксируется в описании источника без добавления новых строк в таблицу.

Обозначения языковых версий: `PL` — польский оригинал, `RU` — русский перевод,
`EN` — английский перевод. «Страницы PDF» — порядковые страницы локального
файла, «печатные страницы» — пагинация самого издания.
